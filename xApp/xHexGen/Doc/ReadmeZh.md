# xHexGen

> **Project** : xHexGen
> **Author**  : William Hsiao
> **Descript**: 讀取二進位資料並轉換成陣列資料的工具

## 簡介
`xHexGen` 是一個非常小的實用程序，用於幫助在 `C` 或 `C++` 程式中處理嵌入式檔案。

## 應用大小
1. `xHexGen` 應用大小: `4.488KB`

## 編譯
1. 使用 `CMake` 編譯

``` shell
mkdir build
cd build
cmake ..
make
```

2. 使用 `Shell` 編譯
  1. 建立 `build` 資料夾
  2. 執行 `CMAKE` 指令
  3. 執行 `Make` 指令

``` shell
./Build.sh
```

3. 使用 `Shell` 清理

``` shell
./Build.sh clean
```

## 使用
``` shell
> xHexGen ./In/Res.jpg > Res.c
> cat Res.c
```
