# xLib

## 簡介
`xLib` 是一個遵循極簡主義哲學的 C/C++ 通用函數庫集合。
「x」代表作者的個人標誌，象徵著對代碼純粹性與開發效率的追求。

與傳統龐大、依賴複雜的框架不同，`xLib` 的設計目標是提供一組「即插即用」的小型模組。
因此 `xLib` 的大多數組件都採用 「一頭文件 + 一源文件」 的單檔設計。
對於結構較為複雜的模組，則透過統一的 接口頭文件進行封裝，確保主程式的潔淨與高度解耦。


## 特性
1. 基於 `C99` 標準進行編寫
2. 跨平台設計，不依賴第三方框架
3. 極簡的單檔設計
4. 極簡化程式內容，可以快速入門
5. 組裝式的應用設計


## 分類
1. `xAdapter`: 基於第三方庫、不同功能的統一接口。
2. `xApp    `: 基於實際應用、有目的性、高度完整度的功能之程式。
3. `xDevice `: 基於實際硬體、感測器驅動、硬體模組的功能之程式。
4. `xFake   `: 基於模擬硬體或是用以其他方式模擬軟件功能之程式。
5. `xModule `: 基於純軟體演算法、通用資料、標準協議處理之程式。
